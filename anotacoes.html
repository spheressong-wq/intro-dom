Conhecendo o DOM

O que é o DOM?

DOM significa Document Object Model .

É uma representação do documento HTML em forma de objetos, organizada em uma estrutura hierárquica de árvore, conhecida como DOM Tree.

Note que cada elemento de HTML está conectado. Chamados esses elementos de nó (node) dentro dessa estrutura.

Em outras palavras, o navegador basicamente transforma o HTML em uma estrutura que o Java script consegue acessar e manipular.

Pra que serve a DOM?

O DOM permite que o Javascript interaja com os elementos HTML. Exemplos:

  • Selecionar elementos: Encontrar o botão
  • Alterar conteúdo: Alterar um título, paragráfo...
  • Alterar estilos: Mudar cores, aplicar bordas etc
  • Criar elementos: Criar paragráfos, listas, links e etc
  • Remover elementos: Excluir itens criados e já existentes
  • Capturar eventos: Detectar cliques, teclas pressionadas e etc
  • Modificar atributos: Alterar src, um aria-label etc.
